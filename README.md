# Tic Tac Toe - Full Stack

A full stack Tic Tac Toe game built using HTML, CSS, JavaScript, Node.js, Express, and MongoDB.

## Features
- Play Tic Tac Toe in browser
- Backend API using Express
- MongoDB database connection
- Game results stored in database

## Technologies Used
- HTML
- CSS
- JavaScript
- Node.js
- Express
- MongoDB

## Run the project

1. Clone the repository
git clone https://github.com/UdhayaDev/Tic-Tac-Toe---Full-Stack.git

2. Install dependencies
npm install

3. Start the server
node server.js

4. Open the frontend
Open client/index.html in your browser
